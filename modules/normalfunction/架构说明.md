# NormalFunction 模块架构说明

> 维护约定：每次改动本模块（新增/删除子模块、接口变化、线程模型变化）后，必须同步更新本文件。

## 1. 职责

`modules/normalfunction/` 是「常用工具」区的**独立子模块集合**。它承载**非实时**或**准实时**的辅助功能，与串口 `commtool` 通过门面类间接耦合，避免子模块互相污染、UI 线程被阻塞。

当前包含四个子模块：

| 子模块 | 类型 | 与 commtool 耦合 | 线程模型 |
|---|---|---|---|
| `navcalib/` 超达投影估计 | **实时** | 紧耦合 —— 串收到帧时需调 `submitFrame` | 跟随 commtool 主线程（每帧塞 QVector，无 heavy 计算） |
| `allan/` Allan 方差分析 | **离线** | **零耦合** —— 自己读文件、自己算、自己显示 | 独立 `QThread` + `AllanWorker` |
| `calib612/` 6+12 位置标定 | **离线** | **零耦合** —— 自己读文件、自己算、自己显示 | 独立 `QThread` + `Calib612Worker` |
| `tempdrift/` 拉温温漂分析 | **离线** | **零耦合** —— 自己读文件、自己算、自己显示 | 独立 `QThread` + `TempDriftWorker` |

## 3. 门面类：NormalFunctionModule

**唯一职责**：屏蔽 commtool 对 navcalib/allan 内部的直接依赖，把子模块按钮挂到 UI 上。

### 对外接口

```cpp
class NormalFunctionModule : public QObject {
public:
    // ── NavCalib 接口（给 commtool 串收到帧时调）──
    bool isNavCalibCollecting() const;
    void submitNavCalibFrame(const ParsedFrame &f);
    bool navCalibStrictCrc() const;
    void stopNavCalibCollecting();

    // ── 入口（按钮点）──
    void openNavCalib();
    void openAllan();
};
```

commtool 只持有一个 `NormalFunctionModule *m_normal`，**不再 `#include navcalibpanel.h` 或 `#include allanpanel.h`**。串收到帧时：

```cpp
const bool calib = m_normal && m_normal->isNavCalibCollecting();
// ... 切帧 ...
if (calib) m_normal->submitNavCalibFrame(f);
```

### 生命周期

- 构造：`NormalFunctionModule(Ui::MainWindow *ui, QObject *parent)`
  - 立即创建 Allan 后台 `QThread`（常驻，避免点按钮才启动卡一下）
  - 在 `navCalibButton` **右侧横排**动态 new「Allan 方差分析」按钮（同 180×44 尺寸、继承字体/样式/图标）
  - NavCalibPanel / AllanPanel **延迟创建**（首次点按钮时才 `new`）
- 析构：`m_allanThread->quit(); wait(1000);` 保证后台计算正常收尾

## 4. 线程模型

```
                ┌─────────────────────────────────────────┐
                │              CommTool (UI 线程)         │
                │                                         │
串口/TCP ──► feed() ──► m_framer.feed() ──► ParsedFrame   │
                                                       │
                ┌──────────────────────────────────────┤
                │                                      │
                ▼                                      ▼
   m_ui->realtimeParsePanel                   m_normal->submitNavCalibFrame()
   (同线程，实时显示)                                  │
                                                       ▼
                                              NavCalibPanel
                                              (塞进 QVector，
                                               无 heavy 计算)

                ┌───────────────────────────────────────────┐
                │         NormalFunctionModule              │
                │                                           │
                │   openAllan() ──► 首次创建 AllanPanel      │
                │                                              │
                │   用户选文件 ──► 点击「开始计算」             │
                │       │                                    │
                │       ▼                                    │
                │   QMetaObject::invokeMethod(               │
                │       worker, &AllanWorker::computeQueued,│
                │       Qt::QueuedConnection)               │
                │       │                                    │
                │       ▼                                    │
                │   ╔═════════════════════════════════╗      │
                │   ║   AllanWorker @ m_allanThread   ║      │
                │   ║                                  ║      │
                │   ║  1. QFile 读 CSV                ║      │
                │   ║  2. AllanAnalysis::compute6()    ║      │
                │   ║  3. extractAccel3 / extractGyro3║      │
                │   ║  emit resultReady(mr,acc,gyr)   ║      │
                │   ╚═════════════════════════════════╝      │
                │       │                                    │
                │       ▼  QueuedConnection                  │
                │   AllanPanel::onResultReadyWith()          │
                │   → 填表格 → 画 QLogValueAxis 曲线          │
                └───────────────────────────────────────────┘
```

关键规则：
- **任何超过 100ms 的计算**都必须走后台线程；UI 线程不得直接调用 `AllanAnalysis::compute6`。
- **Worker 上不得直接 new QWidget**；QThread 只能跑无 UI 的 QObject。
- **参数传递**：零参数 slot + 成员变量（`paramsCsvPath/paramsColumns/paramsSkipHead/paramsFs`），避免 `QMetaObject::invokeMethod` 里 `Q_ARG` 对自定义类型做元类型注册。

## 5. Allan 子模块

### 输入约定

- CSV 文件，**用户自行选择 6 列**（前向声明顺序 `[ax, ay, az, gx, gy, gz]`）；
- 跳过头部行数（通常 = 表头行数，默认 1）；
- 采样率 fs（Hz）。
- 面板内置列预览（前 10 行截断），让用户看到每列实际内容再选。
- 6 个列选择下拉**只显示列号 1/2/3…**（表头名放在下拉项 tooltip 里），独立占一行，
  避免和「跳过表头 / 采样率 / 开始计算」挤在同一行导致下拉被压窄看不见。
- 选完文件后按表头关键字（`加计X`/`acc_x`/`ax`、`陀螺X`/`gyr_x`/`gx` 等）自动匹配 6 轴默认列。

### 核心算法

`allananalysis.h/.cpp` 纯静态类，无 Qt 依赖，可独立编译跑测试（验证用例见开发记录：合成 σ=1 deg/s 白噪声 → RW=60.02 deg/√h ✓）。

移植自 `FORSESE_LIB/ALLAN/allan_variance.m` + `allan_good_6axis.m`，non-overlapping 公式：

```
Ω_m(k) = mean( data[kW .. (k+1)W-1] )       % 每窗均值，W=floor(fs·τ)
σ(τ)   = sqrt( ½ · mean( (Ω_{k+1} − Ω_k)² ) )
```

噪声参数提取（**逐项对齐 `work/matlab/allan/` 下的 allan.m + allan_variance.m + mv_filter.m**）：

| 参数 | 加计输入 g → 输出 | 陀螺输入 deg/s → 输出 | 提取方式（MATLAB 同款） |
|---|---|---|---|
| 随机游走 RW | m/s/√h = σ(τ≈1s)×9.8×60 | deg/√h = σ(τ≈1s)×60 | `[~,idx]=min(abs(tau-1))` 最近邻单点 |
| 偏置不稳定性 @10s | μg = σ(τ≈10s)×1e6 | deg/h = σ(τ≈10s)×3600 | 最近邻单点 |
| 偏置不稳定性 @60s | μg = mean(σ(τ=51..70s))×1e6 | deg/h = 同 ×3600 | 20 点平均（中心 60.5 s） |
| 偏置不稳定性 @200s | μg = mean(σ(τ=191..210s))×1e6 | deg/h = 同 ×3600 | 20 点平均（中心 200.5 s） |
| 静态偏置稳定性 | μg = std(mv_filter)×1e6 | deg/h = std(mv_filter)×3600 | `mv_filter(x, fs×10)`：步长 count/2、窗口 count+1 点 |

τ 网格同样照抄 MATLAB：`logspace(0, floor(log10(N/freq)), (floor(log10(N/freq/4))-ceil(log10(1/freq)))*200)`，
**起点恒为 10^0 = 1 s**（不是 1/fs）。Allan 核心计算保留 MATLAB 原样：`W=floor(fs·τ)`、`K=floor(N/W)`、
只对 K≥2 做除零防护，K=2 也正常参与计算（旧版 K<3 丢弃会改变尾部）。

### 输出

- 9×7 表格（5 类参数 × 6 轴 + 3 行元信息）——**面板内只放表格，不再内嵌图表**
- 计算完成后 `showChartWindow()` 弹**两个独立非模态窗口**（各 `WA_DeleteOnClose`、位置错开），
  一张图一个窗口，对应 MATLAB `allan.m` 的两张 figure：
  - 窗口1 加计：`Accelerometer -- Allan variance`，σ×1e6 → **μg**
  - 窗口2 陀螺：`Gyroscope -- Allan variance`，σ×3600 → **deg/h**
  - `QLogValueAxis` 双对数轴，每轴一条 `QLineSeries`（x/y/z 三色），仅跳过非有限值与非正值
- 42991 帧 @100 Hz 全量计算耗时 < 2 s（后台线程 UI 无感）

## 6. Calib612 子模块（6+12 位置标定）

入口：常用工具区「6+12 位置标定」按钮（紧挨 Allan 按钮右侧），面板与 Allan 同构：
选文件 → 预览前 10 行 → 选 6 列（AX/AY/AZ/GX/GY/GZ）→ 填采样率 → 后台计算。

### 输入约定

- 6 列等长数据：加计 `g`、陀螺 `deg/s`；
- 跳过表头行数（选文件时按首行首列是否为数字自动置 0/1，可手动改）；
- 采样率 fs（Hz，默认 100）；
- 陀螺标定速率（deg/s，默认 100，对应转台 ±100°/s）；
- 每段固定 10 s，按 fs 换算点数。

### 检段（不依赖固定下标）

移植自 `FORSENSE_LIB/Calibration/accel_calib.m` + `gyro_calib.m`：

- 静态判定 `zupt`：1 s 滑窗陀螺 `‖std‖ < 0.3 deg/s` 且 `‖mean‖ < 5 deg/s`；
- 加计：在静态点上找 `|a_axis ∓ 1 g| < 0.1`，命中点即段起点，取 10 s 均值；
  六个方向各两轮（12 位置）；第二轮必须等第一次"动起来"后才开始，且整段保持静态；
- 陀螺：1 s 滑窗 `std(‖ω‖) < 0.2` 且 `‖ω‖ ≈ 标定速率 ±10 deg/s` 连续保持 >1 s，
  再按分量落在 `±标定速率 ±10` 判定方向，取 10 s 均值（6 位置）。
- 检不到的方向不会静默跳过，而是在面板日志里逐条列出缺段原因。

### 参数求解

与 MATLAB 相同的最小二乘（`A` 为 4×6 真值矩阵，末行全 1，故 `A·Aᵀ` 对角）：

```
M = L·Aᵀ·(A·Aᵀ)^-1        m = S·t + b,  S = M(:,1:3), b = M(:,4)
S_err(‰) = (diag(S) - 1) × 1000
b_accel(mg) = M(:,4) × 1000 ;  b_gyro(deg/s) = M(:,4)
α β γ = 交叉耦合平均（±两方向之差/4/标称速率）
T = asin(max|C(α,β,γ)·S 的非对角元|) → deg
```

### 输出

- 结果表：加计/陀螺的标度误差（‰）、零偏（mg / deg/s）、加计安装角 α/β/γ（deg）、
  最大非正交角（deg）、数据行数/采样率/每段点数/检出段数；
- 日志：每段的 `方向 + 起点采样点 + 起点时间 + 三轴均值`，以及缺段诊断。

## 7. TempDrift 子模块（拉温温漂分析）

入口：常用工具区「拉温分析」按钮（6+12 右侧）。移植自桌面「拉温」目录的
`test.m` / `test_temp.m`，面板与 Allan / 6+12 同构。

### 输入约定

- 7 列等长数据：加计 `g`、陀螺 `deg/s`、温度 `℃`；
- 跳过表头（选文件时按首行首列是否数字自动置 0/1）；
- 采样率 fs（Hz，默认 100）；
- 保温阈值（℃/min，默认 0.5）：|dT/dt| 小于它判为保温平台，否则为斜坡段。

### 处理链

1. **滑动平均**（与 `mv_filter.m` 一致）：窗口 `fs*10+1` 点（≈10 s）、步长
   `floor(fs*10/2)`（50% 重叠），输出约 0.2 Hz 的慢变量序列；
2. 加计 `g → mg`（×1000），陀螺保持 `deg/s`；
3. 全段指标：峰峰值 `max-min`、样本标准差 `std`；
4. **保温/斜坡分类**：用平滑温度序列算 30 s 窗变化率，`|dT/dt| < 阈值` 记保温；
5. 保温段指标：同轴保温点上的峰峰值、标准差，以及「值-温度」线性拟合斜率（每 ℃）；
6. 连续保温段（≥60 s）汇总为平台列表（平均温度 / 起始时刻 / 时长）。

> 斜坡段的跳变属于热梯度/热应力瞬态，不计入零偏指标；只有保温平台段的
> 峰峰值/标准差/温度系数才是器件真实温漂。

### 输出

- 结果表：6 行（加计 X/Y/Z、陀螺 X/Y/Z）× 峰峰值 / 标准差 / 保温段峰峰值 /
  保温段标准差 / 温漂斜率；
- 日志：数据规模、平滑参数、温度范围、保温点比例、保温平台列表、诊断；
- 曲线：计算完成后弹一个 2×3 窗口，横轴温度、纵轴 mg 或 deg/s，画 6 轴
  的「值-温度」特性（按时间顺序连线，可直接看到升降温的滞回环）。

## 8. NavCalib 子模块

从 `modules/commtool/navcalib` 搬来，**除了文件路径，行为零变化**。

commtool 里原来的两处调用现在变成：

| 原写法 | 现写法 |
|---|---|
| `m_navCalib && m_navCalib->isCollecting()` | `m_normal && m_normal->isNavCalibCollecting()` |
| `m_navCalib->submitFrame(f)` | `m_normal->submitNavCalibFrame(f)` |
| `m_navCalib->strictCrc()` | `m_normal->navCalibStrictCrc()` |
| `m_navCalib->stopCollecting()` | `m_normal->stopNavCalibCollecting()` |
| `new NavCalibPanel(...)` | `m_normal->openNavCalib()` 内部延迟创建 |

## 10. 扩展点

### 新增「零耦合」子模块（类 Allan）

1. 子目录放 `allan/` 同级下，例如 `modules/normalfunction/xyztool/`；
2. 算法核写成纯 C++（不依赖 Qt）；
3. Worker 继承 `QObject`，在 `NormalFunctionModule` 构造时 `new` + `moveToThread`；
4. Panel 只做 UI，计算用 `QMetaObject::invokeMethod(QueuedConnection)` 调度到 Worker；
5. CMakeLists.txt 追加源文件；
6. **不要** include 到 commtool.h / commtool.cpp。

### 新增「紧耦合」子模块（类 NavCalib）

1. 算法核必须能在「串口每帧 callback」里完成（单帧开销 < 1ms），超过就走后台线程；
2. 在 `NormalFunctionModule` 里新增接口（`isXxxCollecting / submitXxxFrame / stopXxxCollecting`）；
3. commtool.cpp 的 `appendRecvData` 里加 `m_normal->xxx...` 调用；
4. CMakeLists.txt 追加源文件 + 确认 `currentFramingMode` 或 `modeForProtocol` 里需要的协议 ID；
5. 搬之前先想清楚：**它是实时还是离线**？实时才紧耦合，否则零耦合。
